# ROADMAP relevant entry

_Append-only. Top-to-bottom is priority order. Status mutates in place; entries are never deleted. DONE/ABANDONED stay for history and are skipped by the planner._
**Theme:** Move from a working boundary-integrated DAG runtime to a production runtime with windowing, joins, declarative config, and observability.
### [R-001] Windowed aggregation node
- **Goal:** New `WindowedAggregateNode` supports tumbling + sliding windows with event-time + processing-time semantics, integrated with existing watermark API.
- **Scope:** `WindowSpec` (tumbling, sliding, session), `WindowAssigner`, `Trigger`, zero-alloc aggregation state with Agrona collections, late-arrival policy (drop vs allow-lateness window).
- **Out of scope:** Custom user-defined windows, session windows (follow-on entry), cross-partition window merging.
- **Acceptance:** Unit test covers tumbling + sliding + late-arrival scenarios, `jmhSmokeCheck` green with window node in benchmark surface, watermark advancement drives window close.
- **Notes:** Window state is per-partition; never cross-partition. Reuses the composite boundary identity so a window's state is keyed to its `(boundaryId, partitionId)` pair.
### [R-002] Stateful two-stream join node
- **Goal:** New `StatefulJoinNode` performs watermark-aligned inner+outer joins on two input streams with per-key timeout eviction.
- **Scope:** `JoinSpec` (inner, leftOuter, rightOuter), per-side key buffer with Agrona map, eviction on watermark advance, out-of-order handling.
- **Out of scope:** N-way joins (>2 streams), broadcast joins, temporal interval joins.
- **Acceptance:** Inner+outer join test against seeded two-stream fixture, timeout eviction test, alloc gate green.
- **Depends on:** [R-001] (shares watermark + state-eviction plumbing).
- **Notes:** Must respect the CONTROL record kind — join state eviction on checkpoint records.
- **Goal:** Load a graph definition from `graph.yaml` at startup so non-Java operators can deploy pipeline changes without recompiling.
- **Scope:** `GraphYamlLoader.fromFile(Path)`, schema for nodes/edges/partitions/watermarks, validation against registered node catalog, error messages for unknown node types.
- **Out of scope:** Hot-reload of YAML (that's R-005), mutation via YAML edit, YAML schema versioning.
- **Acceptance:** Load test for a 5-node graph from YAML, compare loaded `CompiledPlan` to hand-built plan for byte equivalence, load-time < 100ms.
- **Notes:** Load path is startup-only — no YAML parsing on hot paths, ever.
### [R-004] Per-node metrics exporter
- **Goal:** Prometheus/OTel export for per-node events-in, events-out, processing-latency histogram, error count.
- **Scope:** `NodeMetrics` attached to `GraphPartitionRunner`, zero-alloc counters via Agrona, scrape endpoint integration matching `lvc-standard` R-001 conventions.
- **Out of scope:** Per-edge metrics, tracing span propagation, sampling profilers.
- **Acceptance:** Metrics counters visible after a seeded graph run, alloc gate green on metrics-enabled runner, integration test with a mock scrape.
- **Notes:** Reuse the `MetricsSink` interface from `lvc-standard` R-001 once that lands, to keep the observability surface uniform.
- **Goal:** Replace a single node's implementation while the graph is running, draining the old instance and spinning up the new atomically.
- **Scope:** `GraphPartitionRunner.replaceNode(nodeId, newImpl)`, drain-then-swap coordinator with watermark snapshot, rollback on swap failure.
- **Out of scope:** Multi-node atomic swap, topology change (adding/removing nodes), config-driven swap from YAML edit.
- **Acceptance:** Runtime swap test replaces a node mid-run without dropping events, both versions visible in metrics, rollback restores original on simulated swap failure.
- **Depends on:** [R-003] (YAML provides the new node definition), [R-004] (swap diagnostics need metrics).
- **Notes:** Watermark snapshot is the atomicity boundary — old node drains all in-flight events up to the snapshot, new node starts from snapshot+1.
### [R-006] Backpressure policy selector
- **Goal:** Pluggable backpressure policies (`DROP_NEW`, `DROP_OLD`, `BLOCK`, `OVERFLOW_TO_DISK`) exposed via `GraphPartitionRunner.Builder`.
- **Scope:** `BackpressurePolicy` enum + per-edge config, overflow-to-disk via mmap spill file, policy hot-swap at edge level.
- **Out of scope:** Custom policies, priority-based shedding, cross-partition backpressure propagation.
- **Acceptance:** Test matrix covers all 4 policies under sustained overrun, alloc gate green, overflow-to-disk test asserts spill file reads back correctly on drain.
- **Notes:** `OVERFLOW_TO_DISK` should reuse the `MmapJournal` machinery from lvc-standard rather than invent a new spill format.
### [R-007] Graph visualizer/tracer JSON export
- **Goal:** `GraphPartitionRunner.exportTopology(Path)` emits graph structure + per-edge event counts as JSON for external visualization tools.
- **Scope:** `GraphTopologyJson` schema, node+edge+partition export, live counters snapshot, output compatible with Cytoscape or D3 consumption.
- **Out of scope:** Visualizer UI itself, interactive tracing, time-series event traces.
- **Acceptance:** Export produces valid JSON for a 10-node seeded graph, schema round-trips through jq, counters match observed throughput.
- **Notes:** Export is a snapshot, not a stream — callers poll by re-invoking. Keep the schema Cytoscape-compatible out of the box.

# DECISIONS relevant excerpt

**Decision:** Use Aeron (IPC and shared-memory transport) for in-process and inter-process event transport. No Chronicle dependency anywhere. Aeron is currently only wired into `examples`, but the decision applies framework-wide when transport is added.
**Context:** The toolchain is pinned to Java 21 in every subproject's `build.gradle`. Trying to write Java 17 code "just in case" adds maintenance burden and defeats modern features (records, sealed types, pattern matching) that make zero-alloc code safer.
